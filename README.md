### About Me

I lead full-stack teams building payment infrastructure that moves over **$1B annually** to 60,000+ merchants. My stack is TypeScript end-to-end — React on the front, NestJS on the back, AWS CDK defining the infrastructure — and security is baked into every release, not bolted on after.

Before fintech I spent years in healthcare, building HL7 interfaces and HIPAA-compliant scheduling systems across a 14-hospital network. That background taught me to treat every piece of user data like it belongs to a patient, which is exactly the mindset I bring to payments and lending.

I ship **LLM-powered features** to production — most recently a PII-safe chargeback assistant on Amazon Bedrock that improved merchant win rates by 21%. I use AI-first dev tools daily (Claude Code, Cursor, Codex) with the same review and security gates as hand-written code.
